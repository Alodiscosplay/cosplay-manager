Cosplay Manager — Politique de confidentialité

Version de test · mise à jour le 9 octobre 2026

Cosplay Manager est une application de planification et de suivi de la création de cosplays. Elle est actuellement en phase de test auprès d'un groupe restreint d'utilisateurs. Cette page décrit le fonctionnement de cette version ; elle sera mise à jour avant toute évolution de l'application ou de son mode de diffusion.

Fonctionnement de la version actuelle

  • L'application ne dispose d'aucun serveur propre : les données ne transitent ni par l'éditeur de l'application, ni par un tiers.
  • Elle n'affiche aucune publicité et ne mesure pas l'audience.

Données utilisées

  • Adresse e-mail et nom du compte Google : affichage du compte connecté, et séparation des données lorsque plusieurs comptes utilisent le même appareil.
  • Un fichier de données dans le Google Drive de l'utilisateur, rangé dans l'espace réservé à l'application. Ce fichier n'est pas visible dans le Drive et aucune autre application n'y a accès. Il contient les costumes, pièces, étapes, achats et réglages saisis dans l'application.
  • Des fichiers créés par l'application dans le Google Drive, uniquement à la demande de l'utilisateur : le dossier des copies de photos, les sauvegardes de costume déposées sur le Drive et les dossiers WIP envoyés vers Google Slides.

L'application n'a accès à aucun autre fichier du Google Drive.

Lieux de stockage

  • L'appareil, dans le stockage du navigateur, ce qui permet l'utilisation hors ligne. Les photos y restent, sauf si l'utilisateur active la copie vers son Drive.
  • Le Google Drive de l'utilisateur, comme décrit ci-dessus, pour retrouver les données sur ses autres appareils.

Les pages de l'application sont hébergées par GitHub Pages, qui peut conserver des journaux techniques de connexion (comme l'adresse IP) selon sa propre politique de confidentialité.

Suppression des données

  • Sur un appareil : Réglages › Se déconnecter, puis effacement des données du site dans le navigateur.
  • Fichier de données : dans Google Drive, Paramètres › Gérer les applications › Cosplay Manager › Options › Supprimer les données d'application cachées.
  • Photos, sauvegardes et dossiers WIP : fichiers ordinaires du Drive, dans le dossier « Cosplay Manager », supprimables comme les autres.
  • Retrait de l'accès de l'application au compte Google : myaccount.google.com/permissions.

Données Google

L'utilisation des informations reçues des API Google respecte le règlement sur les données utilisateur des services d'API Google, y compris ses exigences d'usage limité. Ces données ne sont ni vendues, ni partagées, ni utilisées à d'autres fins que le fonctionnement de l'application.

Contact

Toute question peut être adressée à cosplay-manager@googlegroups.com.
